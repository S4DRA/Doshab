# VAL redesign assets

- `val-echo-dark.png` is the supplied Echo Sonar logo. `val-echo-dark-256.png` is a proportional resize of the supplied dark variant for navigation. Its geometry was not redrawn.
- `val-echo-icon-32.png`, `val-echo-icon-192.png`, `val-echo-icon-512.png`, and `val-echo-apple-180.png` render that same supplied image at browser and app icon sizes. `val-echo-maskable-512.png` adds 56 pixels of black padding around a proportional 400 pixel render so the mark stays inside the maskable safe area. These icons do not redraw the logo.
- `val-lunar.webp` is an AI-generated monochrome lunar landscape, optimized as WebP. The user authorized a replacement because the original decorative artwork was not supplied separately. It approximates the approved composition; it is not the original reference image.
- The interface is HTML/CSS and live application content. No full-screen mockup is used as an interface background.
